# minecraft_physics

Minecraftで物理の実験・原理の検証を行うYouTubeチャンネルの、**チャンネル固有の知見・実験定義・実行ツール**を置くリポジトリ。

動画制作のうちチャンネルを問わない部分（制作台帳、AIナレーション、字幕、組立、検査、投稿）は
[mitsuo822/movie](https://github.com/mitsuo822/movie) が担当する。

## 制作の流れ

```
① テーマ選定   themes/backlog.yaml から候補を採点          ★人が選ぶ（関門1）
② 実験設計     experiments/Exxx/experiment.yaml を書く     ★人が承認（関門2）
③ 実験・計測   サーバで自動実行 → 毎tickの座標ログ → 理論と比較
④ 台本         実測の結果を元に書く（結果が仮説と違えば、それがネタ）
⑤ 撮影         同じ yaml を再実行して録画（長尺16:9 とショート9:16 を別々に撮る）
⑥ 編集         制作台帳を movie に渡して長尺・ショートを組み立てる
⑦ 検査→投稿    自動検査 → 非公開でアップロード            ★人が確認して公開（関門3）
```

## ディレクトリ

| パス | 中身 |
|---|---|
| `docs/` | 設計（全体設計、チャンネルコンセプト、実験定義の書式、MC実行基盤） |
| `knowledge/` | **知見の蓄積先**。MC物理の仕様、mod、撮影の知見。各項目に「確度」と「実測状況」を書く |
| `themes/backlog.yaml` | テーマ候補と採点 |
| `experiments/` | 実験1つにつき1ディレクトリ。`experiment.yaml` が台本・計測・撮影の正本 |
| `episodes/` | 動画1本につき1ディレクトリ。台本と、movie に渡す制作台帳 |
| `lab/` | 実験の実行・計測・理論モデル・グラフ生成のコード（Python） |
| `mc/` | サーバ設定、mod一覧、データパック、構造物 |

動画・録画素材などの大きなファイルはgitに入れない（`.gitignore` 参照）。台帳からは素材フォルダの相対パスで参照する。
