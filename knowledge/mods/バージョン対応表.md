# バージョン対応表（2026-11-19 時点）

> 対象: 2026-11-19 時点の最新の Java Edition と、計測・撮影の基盤に使う mod（Fabric API、Carpet、Flashback、Replay Mod、Sodium、Iris、Distant Horizons、MiniHUD／Tweakeroo／Servux（と MaLiLib、Litematica）、WorldEdit）と物理系 mod（Create、Create Fabric、Valkyrien Skies ほか）がどの MC バージョンに対応しているか。
> 使う場面: P0 で `mc/mods.yaml` の `mc_version` と各 mod の版を決めるとき。mod を使う回の別インスタンスを立てるとき。MC の更新に追従するか決めるとき。
> 調査日: 2026-11-19 ／ mc_version: Java Edition 1.20.1〜26.3（最新は 26.3、26.4 はスナップショット）
> 関連: [物理系mod.md](物理系mod.md), [Carpet.md](Carpet.md), [計測と可視化のmod.md](計測と可視化のmod.md), [../filming/Flashback.md](../filming/Flashback.md), [../filming/ReplayMod.md](../filming/ReplayMod.md), [../filming/シェーダーと画質mod.md](../filming/シェーダーと画質mod.md), [../rights/mod・シェーダーの利用条件.md](../rights/mod・シェーダーの利用条件.md)

## 要点

- **2026-11-19 時点の最新の Java Edition は 26.3（2026-09-15 公開、「Wilderness Bound」）。** 次の 26.4 はスナップショットの段階（26.4 Snapshot 10）で、minecraft.wiki では正式版は「December 2026」。【一次】[S3]【二次】[S1][S2]
- **2026年から版番号が年ベースになった。** 1.21.11 の次が 26.1（2026-03-24）。Mojang の説明では、年のあとにリリースの番号、その後にパッチ（修正）の番号が続き、Java 版はパッチの番号を別の数として付ける（26.1.1、26.1.2 など）。minecraft.wiki はこの形式を「year.drop.hotfix」と書いている。【一次】[S4]【二次】[S1][S6]
- **26.1 から Java Edition は難読化なしで配布され、Java 25 が必要になった。** mod の更新の負担が減る、と Mojang は説明している。【一次】[S5]【二次】[S6]
- **基盤の mod は全部 26.3 に対応した版が出ている**: Fabric API 0.166.2、Carpet 26.3、Flashback 0.43.6、Replay Mod 2.6.28、Sodium 0.9.2、Iris 1.11.7、Distant Horizons 3.3.4、MiniHUD 0.41.2、Tweakeroo 0.30.1、Servux 0.12.2、WorldEdit 7.4.6（いずれも Fabric 版、2026-11-19 の Modrinth）。【一次】[S10]〜[S22]
- **26.3 の Sodium の安定版は 0.9.2。** それより新しい 0.9.3 系はベータ（最新 0.9.3-beta.5、2026-11-12）。Iris 1.11.7（Fabric・26.3）は、Modrinth の依存関係で Sodium の `mc26.3-0.9.2-fabric` という特定の版を必須（required）にしている。【一次】[S14][S15]
- **物理系の大型 mod は 26.3 に揃わない。** Create Fabric と Valkyrien Skies は 1.20.1 まで、Create（NeoForge）と Create Aeronautics・Sable は 1.21.1 まで。【一次】[S23]〜[S27]
- **Flashback は 1.20.x に対応していない**（Modrinth の対応は 1.21 以降）。Replay Mod は 1.20.1 にも対応している。【一次】[S12][S13]
- **Flashback は Fabric 版だけ、Replay Mod の Forge 版は 1.12.2 まで**（現行の版の Fabric 版は 1.14.4 以降。旧版の一覧には打ち切られた 1.14.2・1.14.3 向けの Fabric 版もある。Replay Mod のドキュメントは境目を 1.14（1.14 以上は Fabric）と書く。[../filming/ReplayMod.md](../filming/ReplayMod.md)）。どちらにも NeoForge 版はない。【一次】[S12][S13]
- **Fabric API は 1.21.1 向けも更新が続いている**（0.116.18+1.21.1、2026-11-09）。【一次】[S10]
- **26.2 で実験的な Vulkan レンダラーが入った。** 既定の設定は「Prefer OpenGL」と同じ動き。【二次】[S7]
- **必要な Java**: 1.18 から Java 17、1.20.5 から Java 21、26.1 から Java 25。古い版の別インスタンスを立てるときは Java も分ける。【二次】[S6][S8][S9]

## 詳細

### 調べ方

- MC のバージョンは minecraft.wiki（`?action=raw` の wikitext）と minecraft.net の公式記事で確認した。
- mod の対応は、Modrinth の各プロジェクトのページに埋め込まれたデータ（対応 MC バージョンの一覧・ローダー・更新日）と、最新の版のページ（版番号・公開日・種類＝release/beta/alpha・対応 MC・ローダー・依存関係・変更履歴）を読んだ。取得はすべて 2026-11-19。
- 下の「対応表（MC バージョン × mod）」はプロジェクト単位の一覧で、**ローダー（Fabric／Forge 等）ごとの区別はしていない**。ローダーまで確かめたのは「26.3 向けの最新版」の表と、個別に書いた版だけ。

### 26.2 の Vulkan レンダラー

- 26.2 に実験的な Vulkan レンダラーが入り、ビデオ設定に「Default」「Prefer Vulkan (Experimental)」「Prefer OpenGL」の3つがある。「Default」は今のところ「Prefer OpenGL」と同じ。いずれ OpenGL から Vulkan に切り替える予定、と書かれている。【二次】[S7]

## このチャンネルでの使い方（提案）

> ※この節は上の事実から導いた提案で、事実ではない。

- **基盤（`profiles.base`）は 26.3 ＋ Fabric にする。** 基盤に挙げた mod がすべて 26.3 の release 版を出している、いちばん新しい MC バージョンが 26.3。`mc/mods.yaml` の候補: Fabric API 0.166.2+26.3、Carpet 26.3、Flashback 0.43.6、Replay Mod 26.3-2.6.28、Sodium mc26.3-0.9.2-fabric、Iris 1.11.7+26.3-fabric、Distant Horizons 3.3.4-26.3、MaLiLib 0.30.2、MiniHUD 0.41.2、Tweakeroo 0.30.1、Servux 0.12.2、Litematica 0.29.1、WorldEdit 7.4.6。Java は 25。（根拠: [S3][S6][S10]〜[S22]）
- **Sodium はベータの 0.9.3 ではなく 0.9.2 に固定する。** Iris 1.11.7 が 0.9.2 を必須に指定しているため。（根拠: [S14][S15]）
- **シリーズの途中で 26.4 に上げない。** 26.4 は 2026年12月予定（minecraft.wiki）。上げるのは、基盤の mod が全部 26.4 の release 版を出し、E001 などの計測をやり直す余裕があるときだけにする。物理の挙動が変わっていないかは毎回【実測】で確かめる（26.2 でベッドの跳ね方が変わった例がある。[物理系mod.md](物理系mod.md)）。（根拠: [S1][S2]、[物理系mod.md](物理系mod.md) の [S19]）
- **mod を使う回のインスタンスは、使う mod ごとに次の3つから選ぶ。**
  - **A. 1.20.1 ＋ Fabric（Create＋Valkyrien Skies）**: Create Fabric 6.0.8.1、Valkyrien Skies 2.4.11、Eureka! 1.6.4、Fabric API。録画は Replay Mod（Flashback は 1.20.x 非対応）。Java 17。Create Fabric と VS 2.4.11 が一緒に動くかは未確認なので、最初に試す。（根拠: [S9][S12][S13][S23][S25][S27]）
  - **B. 1.21.1 ＋ NeoForge（Create Aeronautics）**: Create 6.0.10、Sable 2.0.6、Create Aeronautics 1.3.2。Flashback・Replay Mod が使えないので、録画は OBS などでのリアルタイム録画になる。Iris とは表示の問題がある（[物理系mod.md](物理系mod.md)）。Java 21。（根拠: [S8][S12][S13][S24][S26]）
  - **C. 1.21.1 ＋ Fabric（Sable 単体）**: Sable 2.0.6（Fabric 版）と Flashback 0.39.10、Fabric API 0.116.18。Create は入らない（公式の Fabric 版が 1.21.1 にない）。Sable の `/sable` コマンドだけで足りる実験（振り子・衝突など）向け。Carpet・MiniHUD も 1.21.1 のプロジェクトの対応にはあるが、Fabric 版の版番号は未確認。（根拠: [S10][S11][S12][S17][S23][S26]）
- **各インスタンスの構成は `mc/mods.yaml` の `profiles` に書き、P0 で版番号を確定する直前に Modrinth で再確認する。** この表は 2026-11-19 時点のもので、更新は頻繁（例: Fabric API は 11月だけで 26.3 向けに3回）。（根拠: [S10]）

## わかっていないこと・要確認

- Fabric Loader の最新の版（fabricmc.net は読めなかった）。
- 1.20.1 と 1.21.1 での、Carpet・MiniHUD・Tweakeroo・Servux・WorldEdit・Distant Horizons の Fabric 版の具体的な版番号（プロジェクト単位の対応しか確かめていない）。
- 26.4 の正式リリース日と、各 mod の 26.4 対応の時期。
- Vulkan レンダラー（26.2〜、実験的）を選んだときに Sodium・Iris・Flashback・Replay Mod が動くか。
- Iris 1.11.7 と Sodium 0.9.3 ベータの組み合わせが実際に動かないのか（依存関係の指定だけを見た）。
- 古い版（1.20.1・1.21.1）の物理（重力・抵抗など）が 26.3 と同じか。mod の回で計測した値を基盤の値と比べるなら、同じ実験を両方で【実測】する。
