# knowledge — 知見の蓄積先

| ディレクトリ | 中身 |
|---|---|
| `mechanics/` | MCの物理の仕様（重力、空気抵抗、摩擦、爆発、流体、レッドストーン…）。1つの現象につき1ファイル |
| `mods/` | 使ったmodの挙動、つまずき、設定 |
| `filming/` | MCの撮影技術（カメラ、シェーダー、録画設定） |

## 1項目の書き方

```markdown
## <事実の一文>
- mc_version: 1.21.x
- 確度: 【実測】/【一次】/【二次】/【未確認】
- 根拠: 実験ID・ソースの場所・URL など
- 現実との比較: （あれば）
- 動画で使った回: EP00x
```

確度の意味は `CLAUDE.md` を参照。【未確認】の項目は、実験で【実測】に上げるのが基本の流れ。
