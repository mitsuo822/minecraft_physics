# 日本のマイクラ動画ジャンル

> 対象: 日本語のMinecraft動画が、ニコニコ動画の時代からYouTubeの時代までどう広がってきたかと、いま見られているジャンル（グループ実況、茶番・アニメ、検証・小ネタ、建築、統合版コマンド、ショート）と代表的なチャンネルの規模。
> 使う場面: チャンネルの立ち位置を決めるとき、企画を「どのジャンルの隣に置くか」を考えるとき、タイトルの慣習を確かめるとき。
> 調査日: 2026-11-19 ／ mc_version: 動画市場の話が中心で、MCのバージョンには依存しない。Java版と統合版（Bedrock Edition）の区別が関わる記述だけ版を書いた。
> 関連: [視聴者層とマイクラ動画の規模.md](視聴者層とマイクラ動画の規模.md), [科学・物理・検証系の参考チャンネル.md](科学・物理・検証系の参考チャンネル.md), [伸びている企画パターン.md](伸びている企画パターン.md), [既存のマイクラ物理動画.md](既存のマイクラ物理動画.md), [掛け合い形式.md](https://github.com/mitsuo822/movie/blob/main/knowledge/script/掛け合い形式.md)（ゆっくり実況の歴史）, [AI音声チャンネルの事例とリスク.md](https://github.com/mitsuo822/movie/blob/main/knowledge/channel/AI音声チャンネルの事例とリスク.md)（合成音声チャンネル一般の事例）, [子ども向け設定.md](https://github.com/mitsuo822/movie/blob/main/knowledge/youtube/子ども向け設定.md), [Mojang利用ガイドライン.md](../rights/Mojang利用ガイドライン.md)

## 要点

- 日本のゲーム実況は2000年代後半〜2010年代初めにニコニコ動画で盛り上がり（Wikipedia の節の題は「ニコニコ動画のゲーム実況最盛期」）、2010年代中盤からはYouTubeが主流になった（同「Youtubeが主流に」）。Wikipedia は「2010年代中盤以降はMinecraftの実況動画の再生回数が伸びるようになり」と書いている（この一文には脚注がない）。【二次】[S1]
- 合成音声の「ゆっくり実況」はマイクラ動画でも使われていて、2026-11-19 の検索結果にも題名に「ゆっくり実況」を入れた統合版コマンドの動画がある（§4。形式の歴史は movie の [掛け合い形式.md](https://github.com/mitsuo822/movie/blob/main/knowledge/script/掛け合い形式.md)）。【一次】[S25]
- YouTube 公式は2021年12月15日、マイクラ関連コンテンツの再生が世界で合計1兆回を達成したと発表し、**日本では「今年」（2021年）100億回以上**再生されたと書いた。同じ発表で、YouTube 公式インスタグラムの #MinecraftMuseum の企画に「日本からは まいぜんシスターズ が参加します」と書かれた。【一次】[S3]
- YouTube 公式が「YouTube で人気となったマインクラフト動画のトレンド」として挙げるのは「100 Days」（100日間サバイバル）と「ロールプレイ」（台本に沿って役を演じる）。【一次】[S3]
- 2026-11-19 時点で登録者が多いマイクラ中心の日本のチャンネルは、まいぜんシスターズ 328万人、ウォーターチャレンジ 324万人、ドズル社 295万人、日常組 260万人、カラフルピーチ 250万人、ちろぴの 191万人（YouTube の表示値）。【一次】[S12][S13][S14][S15][S19][S20]　ウォーターチャレンジを「マイクラ中心」としたのは、vidIQ の人気動画の上位5本のうち3本と最新動画の題名にマイクラが入っていたため（上位1本目はOP曲）。【二次】[S31]
- 2025年の「国内トップ登録者増加クリエイター」（YouTube 公式、子ども向けチャンネルは対象外）にマイクラ中心のグループ実況の **ドズル社** が入った。【一次】[S11]
- グループ実況には30分を超える長尺が多く、1時間半を超えるものもある（日常組 1:31:20・1:00:56、KUNの50人クラフト 50:07 など。カラフルピーチの1本は27:17。YouTube 検索結果の表示値）。【一次】[S19][S20][S22]
- YouTube で検索語 `マイクラ 検証してみた` を検索した結果の上位は、「都市伝説」「裏技」「小ネタ」を確かめる動画が中心で、題名に「物理」を含むものはなかった。YASUGOYA（44.5万人）、タコ丸 / 村人狂（32.6万人）などが13〜37分の動画で数十万〜100万回台の再生を得ている。【一次】[S16][S23][S29]
- 統合版（Switch など）向けのコマンド動画は、検索結果では「スイッチ対応」「統合版」を題名に入れたものが多く、100万回を超えるものもある。【一次】[S25]
- タイトルに「【まいくら・マインクラフト】」「【まいくら】」のように**ひらがなの「まいくら」**を併記する例が多い（検索結果で複数のチャンネルに見られる）。【一次】[S23][S24]
- 日本のマイクラ実況者は映画にも声で出ている。2025年の映画『マインクラフト／ザ・ムービー』の日本語吹替に HIKAKIN、SEIKIN、ドズル社・日常組・カラフルピーチのメンバーが参加した。【二次】[S9]

## このチャンネルでの使い方（提案）

> ※この節は上の事実から導いた提案で、事実ではない。

- 日本で検索語 `マイクラ 検証してみた` を検索して出てくるのは都市伝説・裏技の検証が中心で、題名に「物理」を含む動画はなかった。現実の物理と比べる実測は「検証」ジャンルの隣の空いた場所として打ち出せる可能性がある（空いているかは C14 の [既存のマイクラ物理動画.md](既存のマイクラ物理動画.md) で確かめる）。題名に「検証」を入れると、既存の検証ジャンルの視聴者の検索に引っかかりやすいかもしれない（未検証の仮説）。（根拠: [S23]）
- 系統C（極端実験）は「〜な世界で」型の題名と相性がよい形にできる（例の形: 重力が地球と同じ世界で〜）。題名の型の詳細は [伸びている企画パターン.md](伸びている企画パターン.md) と movie の `planning/タイトル.md` で確かめる。（根拠: [S19][S20][S22][S24]）
- 日本のマイクラのグループ実況には30分〜1時間半を超える長尺がある。8〜12分の構成は短い側になるので、「短く密度が高い」ことを売りにするか、シリーズの再生リストで続けて見てもらう設計にする。（根拠: [S19][S20][S22][S23]）
- 統合版（Switch）の視聴者が多いジャンルがある。Java版＋mod で撮る回は、説明欄か画面に Java版のバージョン（例: 1.21.x）と mod 使用を明記し、統合版で再現できるかを一言添えると、統合版の視聴者の混乱を防げる。（根拠: [S25][S8]）
- 題名に「まいくら」を併記している例が多い。採用するかは、タイトル方針（movie の `planning/タイトル.md`）と合わせて決める。（根拠: [S23][S24]）
- 大手グループのメンバーが映画の吹替やコラボ商品に出ている。案件・コラボの話が来たときの扱いは [Mojang利用ガイドライン.md](../rights/Mojang利用ガイドライン.md) と movie の `legal/ステルスマーケティング規制.md` を見る。（根拠: [S9][S21]）
