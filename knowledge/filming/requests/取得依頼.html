保存の決まり

保存先は、リポジトリ直下の media/research/camera/ です。media/ は git の管理外なので、ここに置いたものはリポジトリに入りません。

media/research/camera/

  web/                  MC-184359.pdf  flashback_discord.md ...
  src/                  Flashback/  Cinemalya/ ...（git clone）
  flashback_ui/         versions.txt  01_keyframe_types.png ...
  flashback_files/      リプレイの保存フォルダの中身
  notes/                examples.md

動画1本につき欲しいもの

  • 字幕（.vtt か .srt）。その動画の元の言語の字幕で足ります。手動の字幕がなければ自動生成のものを。
  • 概要欄とチャプター。info.json でも、テキストに貼ったものでも構いません。
  • 映像（優先度Aだけ）。720pで足ります。AIは動画を再生できないので、あとで数秒おきの静止画を切り出して、カメラの動きを見ます。

優先度

  • A 字幕・概要欄・映像。カメラの動きや設定画面を目で確かめたいもの。
  • B 字幕・概要欄。話の内容がわかれば足りるもの。
  • C 余裕があれば字幕・概要欄。統合版の話や、入門の重複。
yt-dlp を使う場合の例

リポジトリの直下で実行します。Bの行は字幕と概要欄だけを取ります（urls_B.txt を urls_A.txt や urls_C.txt に変えれば同じ形で使えます）。Aの行は映像も取ります。字幕がうまく取れない動画は、元の言語だけで十分です。

字幕と概要欄だけ

yt-dlp -a knowledge/filming/requests/urls_B.txt --skip-download --write-info-json --write-subs --write-auto-subs --sub-langs "ja,en" --sub-format vtt -o "media/research/camera/youtube/%(id)s/%(id)s.%(ext)s"

映像も（優先度A）

yt-dlp -a knowledge/filming/requests/urls_A.txt -f "bv*[height<=720]+ba/b[height<=720]" --merge-output-format mp4 --write-info-json --write-subs --write-auto-subs --sub-langs "ja,en" --sub-format vtt -o "media/research/camera/youtube/%(id)s/%(id)s.%(ext)s"

保存した動画と字幕は、手元で調べるためだけに使います。リポジトリに入れない、ほかの人に配らない、映像や音声を自分たちの動画に使わない、の3つを守ります。

  1. ファイルを media/research/camera/ の決まった場所に置きます。全部そろっていなくて構いません。
  2. そのPCで Claude Code を開き、こう頼みます。
    「knowledge/filming/requests/requests.yaml の依頼分を media/research/camera/ に保存した。読んで knowledge/filming を更新して」
  3. AIは、読んだ項目の status を used に変え、知見の確度（未確認 → 二次や一次）を上げます。

クラウドのセッションからは media/ が見えません（git の管理外のため）。読ませるには、保存したPCで実行するか、そのフォルダをセッションにつなぎます。

このページは requests.yaml から作った生成物です。依頼を足す・直すときは requests.yaml を編集して、python knowledge/filming/requests/build.py を実行します。
