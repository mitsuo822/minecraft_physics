# カメラワーク技法（MC のシネマティック撮影）

> 対象: Minecraft Java版を中心に、カメラを動かす技法（キーフレームのカメラパス、周回、ロール、FOV、補間、エンティティの追従）と、それを実現する道具（Replay Mod、Flashback、スペクテイターモード、Freecam、CMDCam、平行投影の mod、統合版の /camera）。録画 mod そのものの機能一覧・書き出し設定は [ReplayMod.md](ReplayMod.md) と [Flashback.md](Flashback.md) に任せ、ここでは「カメラの動かし方」に絞る。
> 使う場面: 実験の撮影計画（`experiments/*/experiment.yaml` の shots）を書くとき。撮影用の mod 構成を決めるとき。
> 調査日: 2026-11-19 ／ mc_version: Java Edition 1.16.2〜26.3（mod ごとに対応範囲を表に記載。対応範囲は 2026-11-19 時点の Modrinth の表示）、統合版 1.20.30〜26.10（/camera）
> 関連: [ReplayMod.md](ReplayMod.md), [Flashback.md](Flashback.md), [録画設定.md](録画設定.md), [縦型撮影.md](縦型撮影.md), [時間制御とスロー.md](時間制御とスロー.md), [ワールド内の演出.md](ワールド内の演出.md), [../../docs/MC実行基盤.md](../../docs/MC実行基盤.md)

## 要点
- **平行投影（orthographic）で撮る手段として今回確認できたのは3つ**: Flashback の投影法（Projection）の選択肢『Orthographic』（0.40.0 で追加、MC 26.1.x 向けの版）、Fabric の OrthoCamera（MIT）、Fabric/Forge/NeoForge の Pixelshot（MPL-2.0）。【一次】[S2][S3][S5][S6]
- Sodium と併用するとき、OrthoCamera は Sodium の『Use Block Face Culling』を切る必要がある（切らないと大きな縮尺でブロックの面が描かれないことがある）と、Pixelshot は最良の見た目のために同じ設定を切るよう、それぞれの Modrinth のページに書いている。【一次】[S5][S6]
- Replay Mod のカメラパスは既定で3次スプライン補間（Cubic Spline Interpolation）で、O キーで線形と切り替える。位置キーフレームは x, y, z, yaw, pitch, roll を持つ。【一次】[S1]
- Flashback のキーフレームの種類は Camera / Camera Orbit / Camera Shake / FOV / Freeze / Speed / Timelapse / Time of day / Track Entity / Block Override / Audio Track。補間は Smooth / Linear / Ease In / Ease Out / Ease In/Out / Hold / Hermite から選ぶ（言語ファイルの表示名、取得: 2026-11-19）。【一次】[S2]
- Flashback では左右の矢印キーで再生位置を1tickずつ動かせる。上下の矢印キーで前後のキーフレームに飛ぶ。【一次】[S2]
- Flashback の Freeze には、指定した tick 数をかけて徐々に遅くして止める遅延の設定がある。【一次】[S2]
- スペクテイターモードでは、攻撃ボタンでエンティティをクリックするとその視点に入れる。点火した TNT や防具立ても対象（Java版）。【二次】[S9]
- Freecam（Fabric/Forge/NeoForge、MIT、1.16.2〜26.3）はプレイヤーと別にカメラを動かす mod で、F4＋数字キーで複数の固定カメラ（tripod）を切り替えられる。【一次】[S7]
- CMDCam はコマンドでカメラパスを作って再生でき、サーバ側のコマンドで特定のプレイヤーにパスを再生させることもできる。ただし録画機能はなく、ローダーは Forge/NeoForge のみ（2026-11-19 時点）。【一次】[S8]
- /camera は統合版と教育版の専用コマンド。イージング付きの移動、FOV の変更、エンティティの注視があり、統合版 26.10 からはビヘイビアパックのスプラインを再生する play_spline が実験的機能なしで使える。【二次】[S10]
- Java版の FOV の設定値は縦方向の視野角（既定 70、範囲 30〜110）。【二次】[S11][S12]

### 2. キーフレームでカメラパスを作る

**Replay Mod**（ドキュメントの対象バージョンは不明）
- カメラパスはキーフレームで作り、あとで動画にレンダリングできる。【一次】[S1]
- キーフレームのタイムラインは10分の長さで、時刻はリプレイ内の時刻ではなく実時間を表す。【一次】[S1]
  > 「The Keyframe Timeline is 10 Minutes long, meaning a Camera Path can take up to 10 Minutes.」[S1]
- 位置キーフレームはカメラの位置と向きを保存する。【一次】[S1]
  > 「A Position Keyframe stores a Camera Position (x, y, z, yaw, pitch, roll).」[S1]
- H キーでカメラパスを画面に表示でき、プレビューは補間の設定に従う。【一次】[S1]
- 時間キーフレームはリプレイ内の時刻を表し、同じ時刻のキーフレームを2つ置くとその区間はリプレイの時間が止まる。時間を逆に戻すことはできない。【一次】[S1]
  > 「Two Time Keyframes with the same Timestamp will freeze the Replay time for the duration of their interval.」[S1]
- 再生速度のスライダーは 0.1倍〜8倍。【一次】[S1]
- X キーで『Keyframe Repository』を開き、カメラパスをプリセットとして保存・読み込みできる（リプレイのファイルごと）。【一次】[S1]
- Ctrl+Z / Ctrl+Y でキーフレームの変更を取り消し・やり直しできる。【一次】[S1]

**Flashback**（master ブランチの言語ファイル、取得: 2026-11-19）
- キーフレームはトラックに置き、トラックごとに有効・無効、色、削除を設定できる。【一次】[S2]
- キーフレームは Ctrl+C / Ctrl+V でコピー・貼り付けできる。【一次】[S2]
- I / O キーで書き出す区間（イン点・アウト点）を決める。【一次】[S2]
  > 「Use the [I] and [O] keybinds to set In/Out points on the timeline, controlling what section is exported」[S2]
- 再生位置を1tick単位で動かせる。【一次】[S2]
  > 「Use the left/right arrow keys to move the playhead forwards/backwards 1 tick.」[S2]
- Timelapse のキーフレームは2つ必要で、左を基準の時刻、右をタイムラプスの長さにする。【一次】[S2]
- 0.40.0 で、キー割り当ての変更、『Add Camera』のキー（既定は未割り当て）、ロールのキー（既定は未割り当て）が加わった。【一次】[S3]

**CMDCam**（Forge/NeoForge）
- P キーで地点を追加し、U キーで再生する（既定の長さは10秒）。`/cam add`、`/cam start`、`/cam save` などのコマンドでも操作でき、パスはワールドごとに名前を付けて保存できる。【一次】[S8]
- サーバにも入れれば、コマンドでプレイヤーにパスを再生させられる。【一次】[S8]
  > 「Make a player follow a path by using a command. It's even possible to create paths using commands!」[S8]
- 録画は別のツールが要る。【一次】[S8]
  > 「Just keep in mind that you need an external tool to record it.」[S8]

### 3. 補間（滑らかさ）

| 道具 | 補間の種類 | 既定 | 確度・出典 |
|---|---|---|---|
| Replay Mod | Cubic（3次スプライン）、Linear | Cubic | 【一次】[S1] |
| Flashback | Smooth、Linear、Ease In (Linear Out)、Ease Out (Linear In)、Ease In/Out、Hold、Hermite | 設定『Default Interpolation』で選ぶ | 【一次】[S2] |
| CMDCam | linear、cosine、cubic、hermite、circular | hermite | 【一次】[S8] |
| 統合版 /camera | linear、spring、in/out/in_out × sine・quad・cubic・quart・quint・expo・circ・back・elastic・bounce | linear（FOV の場合） | 【二次】[S10] |

- Replay Mod の既定の補間は、すべての位置キーフレームを通る滑らかな曲線。【一次】[S1]
  > 「By default, Camera Paths follow a smooth curve through all of the set Position Keyframes.」[S1]
  > 「This curve is generated using Cubic Spline Interpolation.」[S1]
- Replay Mod で直線の経路にしたいときは設定で線形に変える（O キーで切り替え）。【一次】[S1]
- Flashback では、キーフレームを右クリックして『Type』を変えると補間が変わる。【一次】[S2]
- Flashback の『Use Realtime Interpolation』は、キーフレーム間を実時間の差で補間する設定で、切ると tick の差で補間する。【一次】[S2]
- Flashback 0.19.0 で、種類の違う補間を混ぜたときにカメラの回転の補間が正しくない不具合が直された。【一次】[S14]
- CMDCam の `/cam distance_timing` は、距離に応じて時間を配分してカメラを一定の速さで動かすための設定。【一次】[S8]
  > 「Can be used to make camera go with constant speed.」[S8]
- CMDCam の `/cam spinning_fix` は、地点間の360°回転の扱い（近い向きに回るか、元の回転方向を保つか、補正しないか）を決める。【一次】[S8]

### 4. 周回・ロール・FOV・揺れ

**周回（オービット）**
- Flashback には『Camera Orbit』というキーフレームの種類がある（パラメータの意味は言語ファイルからは読み取れない）。【一次】[S2]
- 統合版 /camera には周回のプリセット `minecraft:follow_orbit`（1.21.40 で実験的機能から外れた）と `minecraft:fixed_boom`（1.21.70 で実験的機能から外れた）がある。【二次】[S10]

**ロール（カメラの傾き）**
- Replay Mod は J で時計回り、L で反時計回りに傾け、K で戻す。Ctrl を押しながらだと遅く細かく傾けられる。【一次】[S1]
- Flashback には『Camera Roll』の項目とロールのキー割り当てがある。【一次】[S2][S3]
- CMDCam は G / J で左右に傾け、H で戻す。【一次】[S8]

**FOV（ズーム）**
- Flashback には『Override FOV』と FOV のキーフレームがある。【一次】[S2]
- CMDCam は V でズームイン、N でズームアウト、B で戻す。`/cam add` で地点ごとに FOV を指定できる。【一次】[S8]
- 統合版 /camera の `fov_set` は FOV を 30〜110 の範囲で変え、イージングの時間と種類を指定できる（統合版 1.21.111 で実験的機能から外れた）。【二次】[S10]
- Java版の FOV の設定値は縦の視野角で、他のゲームと同じ数値でも見え方が違うことがある。【二次】[S11]
  > 「In Minecraft, the FOV value represents how many degrees of vertical vision the player gets without modifying effects such as sprinting, flying or status effects.」[S11]
- Java版の options.txt で `fov` は 30〜110、既定 70。走ったときなどに FOV が変わる量は `fovEffectScale`（0〜1、1.16.2 から）。【二次】[S12] → ゲーム内設定は [録画設定.md](録画設定.md)

**揺れ**
- Flashback の『Camera Shake』のキーフレームは X / Y それぞれの周波数と振幅を設定できる。【一次】[S2]

### 5. エンティティを追う・エンティティの視点で撮る

- Replay Mod はリプレイ中に生き物（プレイヤーを含む）を右クリックしてその視点に入れる。カメラパスでエンティティの視点に入るには、同じエンティティの視点で作った『Spectator Keyframe』が2つ以上要る。通常の位置キーフレームを置くと視点から抜ける。【一次】[S1]
- Flashback の『Track Entity』のキーフレームは、追う部位（Head / Body / Root）、向きのずれ（Yaw Offset / Pitch Offset）、位置のずれ、視点のずれを設定できる。【一次】[S2]
- Flashback は、プレイヤーの視点に入るだけならカメラのキーフレームは要らないと表示する。【一次】[S2]
  > 「Camera keyframes aren't needed for spectating a player!」[S2]
- Flashback で自分の一人称視点を書き出す予定なら、録画時の一人称の位置・向きの更新回数を書き出しのフレームレートまで上げるよう設定の説明にある。【一次】[S2]
- CMDCam は `/cam target` で注視する対象、`/cam follow` で位置を追う対象（ブロックやエンティティ）を決め、`pitch step` / `yaw step` / `pos step`（既定20、1で即時）で追従の速さを決める。【一次】[S8]
- 統合版 /camera は `target_entity` で注視の対象を決め、`attach_to_entity` でカメラをエンティティに付けられる（統合版 26.10 で実験的機能から外れた）。【二次】[S10]

### 6. 平行投影（orthographic）

- 平行投影では、遠くの物も近くの物も同じ縮尺で描かれる。MC は通常は透視投影で描画する。【一次】[S5]
  > 「In the orthographic view, all objects appear at the same scale.」[S5]
- **OrthoCamera**（Fabric、クライアント側、MIT）: 設定画面（ModMenu かホットキー）で、X と Y の縮尺、視錐台の手前と奥の面の距離、マウスでの回転を止める固定カメラ、固定カメラの角度と回転の速さ、起動をまたいで有効状態を保つか、を設定できる。ホットキーは8つ（切り替え、縮尺の拡大・縮小、固定、固定カメラの回転）。【一次】[S5]
- OrthoCamera は Sodium と併用するなら Sodium の『Performance』タブで『Use Block Face Culling』を切る必要があり、切らないと大きな縮尺でブロックの面が描かれないことがある。Nvidium はこの設定を強制的に有効にするので外す必要がある。変更後は F3+T が要ることがある。【一次】[S5]
  > 「Using Sodium mod, you have to disable "Use Block Face Culling" in "Performance" tab.」[S5]
- **Pixelshot**（Fabric/Forge/NeoForge、クライアント側、MPL-2.0。説明文の末尾に「© 2026 @heyitsfuzs.」の表記）: 平行投影のカメラ、最大16Kの高解像度スクリーンショット、360°パノラマ。ズーム・回転・表示をメニューかキーで調整する。Sodium と使うときは、最良の見た目のために『Use Block Face Culling』を切るよう書いている（OrthoCamera のような「必要」という書き方ではない）。【一次】[S6]
  > 「Using with Sodium: Disable Use Block Face Culling for best visuals.」[S6]
- Pixelshot は Freecam と組み合わせられると書いている。【一次】[S6]
  > 「Works perfectly with the Freecam mod by hashalite for free camera movement.」[S6]
- **Flashback** 0.40.0（MC 26.1.x 向けの版、Modrinth の表示で『7 か月前』の公開、取得: 2026-11-19）で投影法が3つ（Orthographic / Cube Map / Equirectangular）加わった。投影法の選択が書き出しの画面にあるのか編集画面にあるのかは、変更履歴と言語ファイルからは読み取れない。【一次】[S3]
  > 「Added "Orthographic" projection」[S3]
- Flashback の言語ファイルでは『Projection』の選択肢が Perspective / Orthographic / Cube Map / Equirectangular の4つ。【一次】[S2]

### 7. リアルタイムで撮る: スペクテイターモードと Freecam

**スペクテイターモード**（Java版、minecraft.wiki の現行版の記事）
- 飛行し、ブロックやエンティティを通り抜け、他のプレイヤーやモブから見えない。HUD は字幕とチャット以外表示されない。【二次】[S9]
  > 「Spectators can move through blocks, entities and other players.」[S9]
- 常に飛行状態で、マウスホイール（Java版のみ）とダッシュのキーで速さが変わる。最高速度はダッシュなしで 43.556 m/s、ダッシュで 87.111 m/s。【二次】[S9]
- エンティティを攻撃ボタンでクリックするとその視点に入り、位置がそのエンティティに固定される。点火した TNT、防具立て、エンドクリスタルなども対象。降りるキー（dismount key、既定は Shift）で抜ける。統合版・教育版では他のエンティティの視点には入れない。【二次】[S9]
- クリーパー・エンダーマン・クモの視点では画面に特殊な効果がかかり、F4 で効果だけ外せる。【二次】[S9]
- 操作設定『Highlight Players (Spectator)』（既定は未割り当て）を押している間、他のプレイヤーが発光して見える（Java版）。【二次】[S9]
- Java版 26.3（snap4）から、スペクテイターでもポータルで移動できるようになった。【二次】[S9]

**Freecam**（MIT。作者名 hashalite は Pixelshot の説明文の表記 [S6]）
- 有効にしている間、カメラだけが描画距離の範囲を飛んでブロックを通り抜け、無効にすると元の位置に戻る。既定の切り替えキーは F4。【一次】[S7]
- F4＋1〜9 で tripod モードに入り、複数の視点のカメラを置いて切り替えられる。【一次】[S7]
  > 「This enables you to set up multiple cameras with differing perspectives, and switch between them at will.」[S7]
- 『Control Player』で、カメラの視点を保ったままプレイヤーの操作に戻せる（既定は未割り当て）。【一次】[S7]
- 飛び方は DEFAULT（一定速度で流れない）と CREATIVE（クリエイティブの飛行）から選び、水平・垂直の速さを別に決める（既定 1.0）。【一次】[S7]
- マルチプレイでも動くが、サーバによってはチート扱いになると書いている。【一次】[S7]
  > 「This mod works in multiplayer, but may be considered cheating on some servers.」[S7]

### 8. 統合版の /camera（参考。Java版には無い）

- 統合版と教育版の専用コマンドで、権限レベルは1。【二次】[S10]
- プリセット: `minecraft:free`（座標と角度を自由に指定）、`minecraft:first_person`、`minecraft:third_person`、`minecraft:third_person_front`、`minecraft:follow_orbit`、`minecraft:fixed_boom`、`minecraft:control_scheme_camera`（実験的機能）。【二次】[S10]
- `ease` の時間・種類、`pos`、`facing`（注視する座標かエンティティ）、`target_entity` は `minecraft:free` のときだけ有効。`rot` は `minecraft:follow_orbit` でも使え、そのときはプレイヤーの向きも変わる。【二次】[S10]
- `fade` で画面を色で覆ってから戻せる（各段階 0〜10 秒）。テレポートを隠す使い方が例に載っている。【二次】[S10]
- 履歴: 1.20.30 で実験的機能なしで使えるようになり、同じ tick に複数の /camera を実行すると後の1つだけが効く不具合も 1.20.30 で直った。26.0 で `play_spline`（ビヘイビアパックのスプラインを再生）が実験的機能として加わり、26.10 で `attach_to_entity`・`detach_from_entity`・`play_spline` が実験的機能から外れた。【二次】[S10]

### 9. 作り手の経験談

- 個人の note 記事（2021-03-15。記事の環境は replaymod-1.16.4-2.5.2、OptiFine 1.16.5、ワールドを Java 1.16.5 に上げて撮影）で、録画中はプレイデータを集めるだけなのでカメラワークは気にしなくてよく、あとでリプレイビューアーでカメラワークを付けると説明している。【二次】[S13]
  > 「これはプレイデータの収集なのでカメラワーク等を気にする必要はない。」[S13]
- 同じ記事で、Replay Mod はプレイヤーを中心に描画距離の範囲だけを記録するので、撮りたい範囲に合わせて描画距離を決めるよう書いている。64チャンクの描画はクラッシュしやすくなったという体感も書いている。【二次】[S13]
  > 「ReplayModではプレイヤーを中心とした描画距離の円(または球)の中をプレイデータをして収集する。」[S13]
- 同じ記事で、Replay Mod のレンダリングには ffmpeg が要ると書いている（現行版の事情は [ReplayMod.md](ReplayMod.md)）。【二次】[S13]
  > 「ReplayModはレンダリングするためにffmpegが必要になる。」[S13]

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。

- **計測ショット（真横・真上からの軌跡）は平行投影で撮る候補にする。** 平行投影は奥行きで縮尺が変わらないので、ブロックの格子を目盛りとして画面上で長さを比べやすい。まず Flashback の投影法『Orthographic』で書き出せるかを試し、縮尺の指定方法と編集画面での見え方を確かめる。足りなければ OrthoCamera（固定カメラ＋縮尺）でリアルタイム録画する。Sodium を入れるなら『Use Block Face Culling』を切る。（根拠: [S2][S3][S5][S6]）
- **透視投影で撮る計測ショットは FOV を固定する。** FOV のキーフレームや走ったときの FOV の変化があると画面上の大きさが変わる。`fovEffectScale` を 0 にし、FOV のキーフレームは見せ場のショットだけに使う。（根拠: [S2][S11][S12]、ゲーム内設定は [録画設定.md](録画設定.md)）
- **補間はショットの役割で使い分ける。** 計測ショットは固定（Hold）か一定速度（Linear）、見せ場は Smooth / Ease In/Out。Replay Mod の既定は3次スプラインなので、等速が欲しいときは O キーで線形にする。（根拠: [S1][S2][S8]）
- **計測ログの tick と映像を合わせるときは Flashback の1tick送りを使う。** 着地や衝突の tick を画面で確かめられる。（根拠: [S2]）
- **バレットタイム風の演出は Flashback の Freeze（遅延つき）か Replay Mod の同時刻の時間キーフレーム**で、時間を止めてカメラだけ回す。詳しい比較は [時間制御とスロー.md](時間制御とスロー.md)。（根拠: [S1][S2]）
- **飛ぶ物の視点のショット**は、スペクテイターモードで点火した TNT などの視点に入る方法と、Flashback の Track Entity / Replay Mod の Spectator Keyframe がある。滑らかさは要確認なので、短いテストで比べる。（根拠: [S1][S2][S9]）
- **全自動の撮影（`docs/MC実行基盤.md` §4）では、CMDCam のコマンド駆動の仕組みが参考になる**が、CMDCam は Forge/NeoForge 専用で、このチャンネルの基盤（Fabric）にはそのまま入らない。Fabric で自作する場合の機能の見本（地点・注視・追従・一定速度・回転の補正）として使う。（根拠: [S8]）
- **リアルタイムで複数アングルを撮るなら Freecam の tripod**（F4＋数字）で固定カメラを切り替える。HUD は F1 で消す（[録画設定.md](録画設定.md)）。（根拠: [S7]）
- **録画の範囲は描画距離で決まる**という経験談があるので、Replay Mod で撮るときは撮影範囲を描画距離に収める。（根拠: [S13]）

## わかっていないこと・要確認
- Flashback の『Orthographic』が書き出し専用か、編集画面のプレビューにも反映されるか。縮尺（1ブロックが何px か）を数値で決められるか。どの版から 26.1 より前の MC でも使えるか（0.40.0 の対応は 26.1.x のみの表示）。
- OrthoCamera / Pixelshot を Replay Mod や Flashback と同時に入れたときに平行投影のまま録画・書き出しできるか。検索では情報が見つからなかった（2026-11-19）。
- Replay Mod に FOV のキーフレームがあるか。読んだドキュメントの『Camera Paths』の章には記述がなかった。現行版に補間の種類が増えているかも未確認（ドキュメントは Linear と Cubic のみ）。
- Flashback の『Camera Orbit』『Camera Shake』の各パラメータの意味と使い方（言語ファイルの表示名しか読めていない）。
- スペクテイターでエンティティの視点に入ったとき、カメラがクライアント側で滑らかに補間されるか、20tick/秒の刻みが見えるか。
- CMDCam に Fabric 版があるか（Modrinth の表示は Forge/NeoForge のみ）。
- MC の映像クリエイターのチュートリアル動画（本人談）は今回は中身を読めていない（YouTube の本文は取得できない）。読めるホストで探し直す。
- 統合版 /camera の `play_spline` のスプラインの書き方（Microsoft Learn は今回読めないホスト）。
