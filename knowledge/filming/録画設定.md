# 録画設定

> 対象: Java版を録画するときのゲーム内の設定（HUD の非表示、FOV、画面の揺れ、GUI の大きさ、描画距離、シネマティックカメラ、fps の上限）と、リアルタイム録画（OBS）と Replay Mod の書き出しの違い。OBS Studio の録画設定（NVENC、レート制御、録画形式）と GPU（RTX 4070 Ti SUPER）の NVENC の仕様は MC 以外の画面録画にも共通するので、movie リポジトリの [画面録画とエンコード.md](https://github.com/mitsuo822/movie/blob/main/knowledge/editing/画面録画とエンコード.md) に任せる。
> 使う場面: 撮影前の設定チェック。録画方式を選ぶとき（OBS の録画プロファイルを作るときは movie の [画面録画とエンコード.md](https://github.com/mitsuo822/movie/blob/main/knowledge/editing/画面録画とエンコード.md)）。
> 調査日: 2026-11-19 ／ mc_version: Java Edition。ゲーム内設定は minecraft.wiki の Options / Controls の記事（2026-11-19 取得。26.3 までのリリースと 26.4 の開発版の記述を含む）による。項目ごとに追加・変更のバージョンを書く。統合版は対象外。比較表の OBS の記述は GitHub の master ブランチの表示文言（2026-11-19 取得。どのリリース版に当たるかは未確認）。
> 関連: [シェーダーと画質mod.md](シェーダーと画質mod.md), [ReplayMod.md](ReplayMod.md), [Flashback.md](Flashback.md), [カメラワーク技法.md](カメラワーク技法.md), [縦型撮影.md](縦型撮影.md), [時間制御とスロー.md](時間制御とスロー.md), [YouTube のアップロード仕様（movie）](https://github.com/mitsuo822/movie/blob/main/knowledge/youtube/アップロード仕様と書き出し設定.md), [画面録画とエンコード（movie）](https://github.com/mitsuo822/movie/blob/main/knowledge/editing/画面録画とエンコード.md)

## 要点
- F1（Toggle GUI、`key.toggleGui`）で HUD を消す。このキーは 1.21.11（25w41a）から割り当てを変えられる。F2 でスクリーンショット。【二次】[S2]
- シネマティックカメラ（`key.smoothCamera`）は、今の既定ではキーが割り当てられていない。マウスの動きを平滑化する機能。【二次】[S2]
- FOV の値は縦の視野角。既定の 70（Normal）は 16:9 で横 102.4°、最小の 30 は横 50.9°、110 は Quake Pro と表示される。【二次】[S1]
- 走る・飛ぶで視野が変わる効果は「FOV Effects」、歩くときの揺れは「View Bobbing」、吐き気などの歪みは「Distortion Effects」で切れる（FOV Effects と Distortion Effects は 1.16.2 で追加）。【二次】[S1]
- 1.21.2 で追加された「Reduce FPS when」は既定が AFK で、プレイヤーが1分動かないと 30 fps、計10分で 10 fps に制限される。固定カメラの長回しに関わる。【二次】[S1]
- Max Framerate の既定は 120 fps、VSync の既定は ON。【二次】[S1]
- 描画距離の上限は 32 チャンク（半径 512 ブロック。1GB 以上のメモリを割り当てたとき）。エンティティは Entity Distance 100% で 160 ブロックまで見え、プリセット Fast / Fancy / Fabulous! の既定は 75% / 100% / 125%。パーティクルは Fast だと Decreased。【二次】[S1]
- 1.21.11 でグラフィックの Fast / Fancy / Fabulous! が「プリセット」になり、中の設定を1つずつ変えられるようになった。同じ版で Chunk Fade（既定 0.75 秒）が追加された。【二次】[S1]
- Replay Mod は、録画中の fps にふつう影響しないと公式 docs が説明する。書き出しは FFmpeg で行い、docs に挙がるエンコードのプリセットは x264（MP4 / MKV）、vp8（WEBM）、PNG・OpenEXR の連番で、NVENC を使うプリセットは挙がっていない（FFmpeg の引数は書き換えられる）。【一次】[S8]

## 詳細

### ゲーム内: 撮影に関わるキー（Java Edition）
| キー（既定） | 機能（キー名） | 内容 | 確度・出典 |
|---|---|---|---|
| F1 | Toggle GUI（`key.toggleGui`） | HUD の表示を切り替える。1.21.11（25w41a）で「The key to toggle GUI can now be rebound.」 | 【二次】[S2] |
| F2 | Take Screenshot（`key.screenshot`） | スクリーンショットを .minecraft/screenshots に保存。F1 と組み合わせて HUD なしで撮れる | 【二次】[S2] |
| 割り当てなし | Toggle Cinematic Camera（`key.smoothCamera`） | 「Toggles mouse smoothing. Looking around becomes a slow, smooth and more cinematic motion.」 | 【二次】[S2] |
| F5 | Toggle Perspective（`key.togglePerspective`） | 一人称、背後からの三人称、正面からの三人称を切り替える | 【二次】[S2] |
| F11 | Toggle Fullscreen（`key.fullscreen`） | 全画面の切り替え | 【二次】[S2] |
| F4 | Toggle Spectator Shader Effects | スペクテイターでモブに入ったときの画面フィルタなどを切り替える。1.21.11（25w41a）で割り当て変更が可能になった | 【二次】[S2] |

- ノートPCの注意: macOS では F キーが既定でシステム機能に割り当てられている。Windows でも「Some Windows laptops exhibit similar behavior」で、Fn ロックを切るか Shift を押しながら押す、と wiki は書く。【二次】[S2]

### ゲーム内: FOV と画面の揺れ
- FOV の意味: 「In Minecraft, the FOV value represents how many degrees of vertical vision the player gets without modifying effects such as sprinting, flying or status effects.」（訳: MC の FOV は、走る・飛ぶ・ステータス効果による変化を除いた、縦方向の視野の角度）。【二次】[S1]
- FOV の値と横の視野（wiki の表）:

| 設定値（縦） | 横（4:3） | 横（16:9） | 確度・出典 |
|---|---|---|---|
| 30° | 39.3° | 50.9° | 【二次】[S1] |
| 50° | 63.7° | 79.3° | 【二次】[S1] |
| 70°（Normal、既定） | 86.1° | 102.4° | 【二次】[S1] |
| 90° | 106.3° | 121.3° | 【二次】[S1] |
| 110°（Quake Pro） | 124.6° | 137.0° | 【二次】[S1] |

- 最小値は 1.7.6（pre1）から 30: 「The minimum FOV setting is now 30 rather than 70.」【二次】[S1]
- FOV Effects（既定 100%）: 「Changes the FOV effects of anything affecting them.」。Distortion Effects（既定 100%）は吐き気やネザーポータルの歪みを変える。どちらも 1.16.2（pre1）で追加: 「Added "Distortion Effects" and "FOV effects" sliders to video and accessibility settings.」【二次】[S1]
- View Bobbing（既定 ON）: 「Toggles the "bobbing" motion of the camera as the player is walking.」【二次】[S1]

### ゲーム内: GUI の大きさ
- 選べる GUI Scale の数は解像度で決まり、式は `max(1, min(floor(width / 320), floor(height / 240)))`。Auto はその解像度で選べる最大値になる。GUI Scale は HUD の大きさも変える。【二次】[S1]
- 上の式に当てはめると、1920×1080 では最大 4、3840×2160 では最大 9 になる（式からの計算）。【二次】[S1]

### ゲーム内: 描画距離・シミュレーション距離・エンティティ・パーティクル
- 描画距離の上限: 「The maximum value is 32 if at least 1 gigabyte of memory is allocated to the game, and 16 in all other cases.」【二次】[S1]
- 遠くの地形は霧のように空の色へ溶ける: 「The most distant terrain is faded into the sky color as if by fog, to avoid a sharp edge to the visible world」【二次】[S1]
- 描画距離とプリセットの既定（wiki の表）: 32 チャンク＝半径 512 ブロック（Fabulous! の既定）、16 チャンク＝256 ブロック（Fancy の既定）、8 チャンク＝128 ブロック（Fast の既定）。【二次】[S1]
- シミュレーション距離は、エンティティの更新とブロック・液体の tick が行われるチャンクの範囲。最小 5 チャンク、プリセット既定は Fast 6 / Fancy・Fabulous! 12。「Simulation distance is more taxing on performance than the equivalent level of render distance.」【二次】[S1]
- エンティティの見える距離: 「At 100% entities are visible up to 160 blocks away.」（描画距離のほうが短ければそちらが優先）。プリセット既定は 75% / 100% / 125%。【二次】[S1]
- パーティクル: All / Decreased / Minimal。プリセット既定は Fast が Decreased、Fancy・Fabulous! が All。【二次】[S1]
- Chunk Fade（既定 0.75 秒）と Anisotropic Filtering は 1.21.11（25w44a）で追加。Cloud Distance は 1.21.6（25w17a）で追加。Improved Fog は 26.4 で追加予定（開発版 snap9）。【二次】[S1]

### ゲーム内: fps とグラフィックのプリセット
- Max Framerate の既定は 120 fps。「Limiting the frame rate to a multiple of the [[player]] monitor's refresh rate can save processing power.」という注記がある。【二次】[S1]
- VSync の既定は ON: 「Enabling VSync fixes tearing, but increases input latency and causes stuttering if one's computer cannot draw enough frames per second.」【二次】[S1]
- Reduce FPS when（既定 AFK。1.21.2 の 24w33a で追加）: AFK はプレイヤーが1分動かないと「the frame rate will be capped at 30 FPS」、さらに「When there is no movement for a total of 10 minutes, the frame rate will be capped at 10 FPS.」。Minimized はウィンドウを最小化したときに 10 fps に制限する。【二次】[S1]
- 1.21.11（25w41a）の変更: 「Graphics modes "Fast", "Fancy", and "Fabulous!" have been replaced with graphics presets with the same names.」「Tweaks that were previously hidden behind the "Graphics" setting have been split out to be configurable independently.」。ビデオ設定は Display / Quality & Performance / Interface（25w44a で Preferences に改名）の3つに分かれた。【二次】[S1]
- Fabulous! は半透明のブロックや水の後ろの天候・雲・パーティクルを画面シェーダーで描く。Fancy は透過した葉、雨のパーティクル増、暗所のビネットなど。【二次】[S1]
- 全画面: 26.1（pre2）で Exclusive Fullscreen の設定が追加。26.3（snap4）で「Borderless Fullscreen is now the default fullscreen mode.」。【二次】[S1]
- 描画 API: 26.2 で OpenGL と Vulkan を選べるようになり、26.4（開発中）では Default が Vulkan 優先。シェーダー mod との関係は [シェーダーと画質mod.md](シェーダーと画質mod.md)。【二次】[S1]
- Brightness の既定は 50（ゲーム内の表示は Default）。【二次】[S1]

### OBS の録画設定と GPU の NVENC（movie 側）
- OBS の録画設定（簡易モードの録画品質と CQP の対応、詳細モードの NVENC の項目、録画形式とクラッシュ時の復元）と、RTX 4070 Ti SUPER の NVENC の仕様、それに基づく録画プロファイル・録画形式・コーデックの提案は、MC 以外の画面録画にも共通するので movie の [画面録画とエンコード.md](https://github.com/mitsuo822/movie/blob/main/knowledge/editing/画面録画とエンコード.md) にまとめた。

### リアルタイム録画（OBS）と Replay Mod の書き出し
| 観点 | OBS でのリアルタイム録画 | Replay Mod の録画→書き出し | 確度・出典 |
|---|---|---|---|
| 録画中の負荷 | NVENC は映像のエンコードを CPU から GPU の専用の部分に移す機能（Wikipedia の説明）。録画中の fps への影響を示す資料は今回読めていない | 「Usually, recording a Replay does not affect your framerate, and it also doesn't lead to lag on servers.」 | OBS 側【二次】[S6] ／ Replay Mod 側【一次】[S8] |
| 録画のデータ | 映像ファイル（形式は movie の [画面録画とエンコード.md](https://github.com/mitsuo822/movie/blob/main/knowledge/editing/画面録画とエンコード.md)） | .mcpr。「An average Replay File of 10 Minutes duration usually is between 2MB and 10MB large.」 | 【一次】[S4][S8] |
| 開始のタイミング | （今回の出典に記述なし） | 「you need to start recording when joining a Server or World」 | 【一次】[S8] |
| 書き出しのエンコード | 簡易モードの選択肢に「Software (x264)」と NVENC（H.264 / HEVC / AV1）など | 「The Replay Mod runs FFmpeg via the Command Line to encode videos.」。プリセットは MP4（x264）の Default / High / Potato / Custom Bitrate、WEBM（vp8）、MKV Lossless（x264）、PNG 連番、OpenEXR 連番（1.14 以上）。docs は「There are 7 Encoding Presets you can choose from」と書くが、列挙されているのは8つ | 【一次】[S4][S8] |
| 解像度 | キャンバスと出力解像度で決める | 「You can enter any resolution there, but make sure to use reasonable values.」 | 【一次】[S4][S8] |
| カメラパス | （今回の出典に記述なし） | 「The Keyframe Timeline is 10 Minutes long, meaning a Camera Path can take up to 10 Minutes.」 | 【一次】[S8] |

- Replay Mod の「MP4 - High Quality」の説明: 「Rendered videos have a relatively high file size, but their quality is almost lossless.」【一次】[S8]
- 書き出しには FFmpeg のインストールが要る: 「To render your creations with Replay Mod you will need to have FFmpeg installed.」。エンコードの引数はユーザーが書き換えられる。【一次】[S8]
- Replay Mod の詳細（キーフレーム、360°、Sodium・Iris との互換）は [ReplayMod.md](ReplayMod.md)、Flashback は [Flashback.md](Flashback.md)。

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。
- 撮影前のゲーム内チェック: F1 で HUD を消す、FOV Effects 0%、Distortion Effects 0%、View Bobbing OFF、FOV は回をまたいで固定（値は `experiment.yaml` の撮影の項目に書く）。（根拠: [S1][S2]）
- 固定カメラで1分以上回すショットがあるので、「Reduce FPS when」を Minimized にしてから撮る。AFK のままだと途中で 30 fps に落ちるおそれがある。（根拠: [S1]）
- 長い距離を飛ぶ実験では、描画距離・シミュレーション距離・Entity Distance を確認する。160 ブロックより先のエンティティは Entity Distance 100% では映らない。軌跡をパーティクルで描く回は、パーティクルを All にする。（根拠: [S1]）
- 計測の映像で遠近の歪みを減らしたいときは FOV を小さくする（30 なら 16:9 で横 50.9°）。本格的には平行投影の mod を検討する（[カメラワーク技法.md](カメラワーク技法.md)）。（根拠: [S1]）
- カメラを動かすショットは Replay Mod / Flashback の書き出し、確認用や長回しの固定ショットは OBS、と使い分ける（どちらが向くかは P2 の比較で【実測】にする）。（根拠: [S8]、`docs/MC実行基盤.md` §4）

## わかっていないこと・要確認
- 「Reduce FPS when」の AFK 判定に、マウスでの視点移動やスペクテイターでの移動が入るか。Replay Mod / Flashback の書き出し中にこの制限がかかるか。
- OBS のリアルタイム録画（NVENC）が録画中のゲームの fps にどれだけ響くか。
- MC 26.2 以降で Vulkan 描画を使ったとき、OBS のゲームキャプチャで問題なく録れるか。26.4 の「Prefer DXGI Present」（Windows のみ）の影響。
- Java 版で F1 が手（持っているアイテム）まで消すか。今回の wiki の Java の行は HUD とだけ書いている。
- YouTube への書き出し設定（ビットレート等）は movie リポジトリの [アップロード仕様と書き出し設定.md](https://github.com/mitsuo822/movie/blob/main/knowledge/youtube/アップロード仕様と書き出し設定.md) で扱う。
