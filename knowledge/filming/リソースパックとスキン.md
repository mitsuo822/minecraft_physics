# リソースパックとスキン

> 対象: 計測映像を見やすくするリソースパック（ブロックの格子・縁取り、組み込みパック、自作パックの仕組み）と、プレイヤー・キャラクターのスキン（スキンの形式、マネキンでの表示、ローカルのスキン）、それぞれの利用条件。シェーダーは [シェーダーと画質mod](シェーダーと画質mod.md)、計測用の表示 mod は [計測と可視化のmod](../mods/計測と可視化のmod.md) を読む。
> 使う場面: P0 環境決め（入れるパックを決める）、② 実験設計（目盛り・格子が要るか）、⑤ 撮影（キャラクターをワールドに置く）、⑥ 編集前の権利確認。
> 調査日: 2026-11-20 ／ mc_version: Java Edition 26.3 を前提（基盤の候補。[バージョン対応表](../mods/バージョン対応表.md)）。機能の追加時期として 1.14・1.19.3・1.19.4・1.21.9 の履歴を含む。統合版（Bedrock）は扱わない。
> 関連: [Mojang利用ガイドライン](../rights/Mojang利用ガイドライン.md), [mod・シェーダーの利用条件](../rights/mod・シェーダーの利用条件.md), [シェーダーと画質mod](シェーダーと画質mod.md), [ワールド内の演出](ワールド内の演出.md), [Flashback](Flashback.md), [計測と可視化のmod](../mods/計測と可視化のmod.md), movie の [キャラクター立ち絵の規約](https://github.com/mitsuo822/movie/blob/main/knowledge/audio/キャラクター立ち絵の規約.md)

## 要点
- **Modrinth でリソースパックを grid で検索し 26.3 で絞ると、ブロック全体に格子を付けるものは『Block Grid』（M家庄少）だけだった（2026-11-20）。** ただしライセンスは ARR（All Rights Reserved）。BSD-2-Clause の『Grid-like Visible Block Edges』は 1.21.4 まで、CC0 の『Colored Block Borders』は 1.20.4 のみの表示（2026-11-20 の Modrinth）。【一次】[S10][S11][S12][S13]
- **組み込みの『High Contrast』パックについて、wiki は内容をメニューの GUI のコントラストを上げるもの、と説明している。** 1.19.4 で追加。ワールドの見た目に効くかどうかは wiki に書かれていない。【二次】[S1]
- **リソースパックは一覧の上にあるものが優先される。** 下のパックから読み、上のパックが置き換える・合成する。格子系のパックの作者は、Block Grid は最上段に、Grid-like Visible Block Edges は優先度を高くして置くよう勧めている。【二次】[S1]【一次】[S11][S12]
- **リソースパックの対応版は pack.mcmeta の番号で決まり、25w31a（1.21.9 の開発版）からは min_format / max_format の2つで書く。** 26.3 の開発版で最後に記録された番号は 97.1（pre1）。ゲーム内の番号は F3+V か /version で確かめられる。【二次】[S1][S2]
- **Java 版のスキンは 64×64 ピクセル（旧形式 64×32）の PNG。** 腕は classic（4ピクセル幅）と slim（3ピクセル幅）の2種類。スキンを変えられるのは Minecraft を購入したプレイヤーだけ。【二次】[S3]
- **既定のスキンは9種類**（Steve・Alex と、2022年に加わった7種類）。1.19.3 で7種類がゲーム本体に入った。【二次】[S3]
- **1.21.9（2025-09-30）で、プレイヤーがいなくても人の姿を出せる『マネキン』（minecraft:mannequin）が入った。** コマンドでだけ出せる。ポーズ（立つ・しゃがむ・泳ぐ・滑空・寝る）や「NPC」表示の有無を指定できる。【二次】[S4][S7]
- **1.21.9 から、マネキンやプレイヤーの頭のスキンを、リソースパック内の画像から直接指定できる**（profile の texture・cape・elytra・model 欄）。wiki は、各テクスチャをリソースパック内の画像のパスか、プレイヤーのプロフィールのどちらかで与えられる、としている。【二次】[S5][S6][S7]
- **プレイヤーのスキンとしてバニラで表示されるのは、Mojang のサービスに登録したものだけ**（クライアントが署名を検証する）。ローカルのスキン画像を使う mod『CustomSkinLoader』は 26.3 に対応（ソースは GPL-3.0-only、公式バイナリは別条件。クライアント側）。【二次】[S3]【一次】[S14]
- **Mojang は、ブロックのテクスチャや自社のキャラクタースキンを自社の知的財産としている。** スキンやパックの内容にも、憎悪表現などを禁じる規約がかかる。【一次】[S8][S9]
- **ずんだもん等（東北ずん子・ずんだもんプロジェクト）は、自分で作った2次創作は使える。他人が作った2次創作は、その作者の許可が要る。** ただし、ガイドラインに準拠した2次創作（準拠を示す表記が（ず・ω・きょ））は使える、という例外も書かれている。個人の YouTube 広告収入は非商用の範囲とされている。【一次】[S16]

## 詳細

### リソースパックの基本（Java Edition 26.3 時点の wiki）
- リソースパックは、テクスチャ・モデル・音楽・効果音・言語・フォントなどを、コードを書き換えずに変える仕組み。【二次】[S1]
- パックはフォルダか ZIP。`.minecraft/resourcepacks` に置くか、リソースパックの選択画面（Select Resource Packs）にドラッグ＆ドロップする（自動でコピーされる）。オプション画面で有効・無効と順番を変える。【二次】[S1]
- 読み込み順は選択中（Selected）の一覧の順。一番下のパックが最初に読まれ、その上のパックが置き換える・合成する。【二次】[S1]
> 「The bottom-most pack loads first, then each pack above it replaces or merges loaded assets with ones it contains.」[S1]
- 必須のファイルは `pack.mcmeta` だけ。`pack.png` は一覧のアイコン。`assets/minecraft/` に同じ名前のファイルを置くとバニラのものを上書きできる。【二次】[S1]
- パックで変えられる範囲には、ブロックの状態ごとのモデル（blockstates）、モデル（models）、テクスチャ（textures）、フォント、言語、パーティクル、シェーダー（core / post）が含まれる。【二次】[S1]
- テクスチャは PNG。1.13 以降はブロックとアイテムに正方形でないテクスチャも使える（既定のモデルでは引き伸ばされる・つぶれる）。テクスチャがどのパック（既定のパックを含む）にもないと、黒とマゼンタの「missing texture」が出る。【二次】[S1]

### ワールド・サーバーに付けるパック
- ワールドのフォルダの `resourcepacks/resources.zip` に置いたパックは、そのワールドを遊ぶときに既定のパックのすぐ上に入る。LAN で接続した他のプレイヤーには配られない。【二次】[S1]

### パックの対応版（pack format）
- pack format は、リソースパック・データパックがどの版に対応するかを表す番号。番号は `/version` コマンドか F3+V で調べられる。パックの番号がゲームの対応より大きいと、一覧で互換性なし（incompatible）と表示される。【二次】[S2]
- 25w31a から、`pack_format` の1つの値ではなく `min_format` と `max_format` の2つの欄で対応範囲を書く形になった。【二次】[S2]
- 履歴（リソースパックの番号）: 1.21.9（25w31a）で 65.0、26.2 で 85.0〜88.0、26.3 の開発版で 89.0〜97.1（最後の記録は pre1 の 97.1）、26.4 のスナップショットで 98.0〜102.0。【二次】[S1]

### スキンの形式（Java Edition）
- スキンはプレイヤーのモデルに貼るテクスチャ。64×64 ピクセルで、内側と外側の2層。外側の層は眼鏡・帽子などに使われ、体・腕・脚では内側より 0.5 ピクセル、頭では 1 ピクセル大きい。【二次】[S3]
- slim のモデルは腕の幅が 25% 細い（3ピクセル）。classic は 4ピクセル。【二次】[S3]
- Java 版では、スキンの内側の層は強制的に不透明になる。外側の層は透明・半透明を使える。【二次】[S3]
- 既定のスキンは Steve・Alex・Ari・Efe・Kai・Makena・Noor・Sunny・Zuri の9種類。Ari・Kai・Steve・Sunny・Zuri は既定で wide（classic）、Alex・Efe・Makena・Noor は slim。【二次】[S3]
- 7種類（Sunny・Efe・Zuri・Noor・Ari・Makena・Kai）は 2022-10-15 の Minecraft Live 2022 で発表、2022-10-20 にランチャーに追加。1.19.3（22w45a）でゲーム本体に入り、オフラインのプレイヤーにも割り当てられるようになった。【二次】[S3]

### スキンの変え方と表示の仕組み
- スキンを変えられるのは購入者だけ。minecraft.net のプロフィールページかランチャーで、64×64（旧形式は 64×32）の PNG を登録する。腕の幅（3 か 4 ピクセル）もそこで選ぶ。【二次】[S3]
> 「Only players who have purchased Minecraft can change their character's skin.」[S3]
- 既定のスキンの画像はリソースパックで差し替えられるが、見えるのはそのパックを使っている人だけで、既定のスキンの全員が変わる。【二次】[S3]
> 「can also be changed and replaced via a resource pack, but the effects are visible only to players using the resource pack, and affects all players with the default skin.」[S3]
- スキンは、サーバーが送るプロフィールに入ったテクスチャの URL と署名で表示され、バニラのクライアントは署名を検証する。そのため、Mojang のサービスに登録したもの以外のスキンは使えず、オフラインモードでは mod なしにスキンを使えない。【二次】[S3]
> 「this ensures that no custom skin outside the ones uploaded through the Minecraft services can be used or tampered.」[S3]
- 一度使われたスキンの署名は Mojang のサービスに残り、NameMC や MineSkin などの外部サービスがたどれる。【二次】[S3]

### マネキン（1.21.9 で追加）
- マネキンは、接続しているプレイヤーがいなくてもプレイヤーの姿を出すエンティティ。Java 版のみ。`/summon` などのコマンドでだけ出せ、自然にはスポーンせず、スポーンエッグもない。日本語版 wiki の項目名は「マネキン」。【二次】[S4]
> 「Mannequins function like a player avatar, even if the player is not connected.」[S4]
- 体力は 20、大きさは高さ 1.8・幅 0.6 ブロック。手に物を持ち、防具を着け、ダメージを受け、属性や効果を持てる。アイテムは拾わない。ワールドボーダーの外でもダメージを受けない。倒れてもアイテムや経験値を落とさない。【二次】[S4]
- 指定できる主な欄: `profile`（スキン）、`hidden_layers`（外側の層を隠す: cape・jacket・左右の袖・左右のズボンの脚・hat）、`main_hand`、`pose`（standing・crouching・swimming・fall_flying・sleeping）、`immovable`（動かない）、`description`（名前の下に出る文字。省略時は「NPC」）、`hide_description`（その文字を出さない）。【二次】[S4]
- 1.21.9 で `/fetchprofile` コマンドも入った。プレイヤー名か UUID でプロフィールを取得し、そのプロフィールのマネキンを出すためのクリックできる文字を表示する。【二次】[S7]
- 1.21.9 は 2025-09-30 公開（『The Copper Age』のゲームドロップ）。【二次】[S7]

### profile でスキンをリソースパックから指定する（1.21.9 以降）
- `minecraft:profile` は、プレイヤーの頭（ブロックとアイテム）とマネキンのモデル、テキストのプレイヤーの顔の描画に使うテクスチャを与える。各テクスチャは、リソースパック内の画像のパスか、プレイヤーのプロフィールから与えられる。【二次】[S6]
- 1.21.9 で次の欄が加わった: `texture`（スキン）、`cape`（マント）、`elytra`（エリトラ）、`model`（`wide` か `slim`）。パスは `textures` フォルダからの相対で、例えば `entity/player/wide/steve` は既定の wide の Steve。欄を省くとプロフィールの値が使われる。【二次】[S5][S7]
> 「If specified, this texture is used when rendering a player model or skin, overriding the skin texture provided by a profile.」[S5]
- `texture` で指定したスキンは、内側の層に透明なピクセルを持てる（プロフィールから解決したスキンは常に不透明）。【二次】[S5]
> 「This skin texture may have transparent pixels on the inner body layers whereas resolved skins' are always opaque.」[S5]
- `texture` を省き、プロフィールからもスキンが来ないときは slim の Alex（`minecraft:entity/player/slim/alex`）になる。`model` を省き、プロフィールからも来ないときは slim のモデルになる。【二次】[S5]
- 1.21.9 で profile の解決の仕方も変わった。`properties` を持つ（または name と id が両方ある・両方ない）ものは静的（Static）で、作った時点のスキンのまま固定される。name か id の片方だけのものは動的（Dynamic）で、クライアントで描画するときに最新の値に解決される（解決までは既定のスキンで表示。ゲーム中に相手がスキンを変えても、クライアントを再起動するまで反映されない）。飾りに使うなら静的が望ましい、と変更点にある。【二次】[S7]
> 「That means skin will be frozen at the moment of component creation.」[S7]

### ローカルのスキンを使う mod（CustomSkinLoader）
- CustomSkinLoader は、スキン・マント・エリトラのテクスチャを、オンラインのスキン API かローカルのファイルから読む mod。2026-11-20 の Modrinth の表示で 26.3 を含む 1.8.x〜26.3 に対応、Fabric・Forge・NeoForge・Quilt、クライアント側、ライセンス GPL-3.0-only、2520万ダウンロード、「先月」に更新。【一次】[S14]
> 「CustomSkinLoader is a Minecraft mod that loads skins, capes, and elytra textures from online skin APIs or local files.」[S14]
- 説明欄では、GPL-3.0-only はソースコードのライセンスで、公式のバイナリは別の条件（改変しないものは modpack で使い・共有してよいが、mod の一覧に載せること。許可なく他のサイトに再掲しない）としている。ローカルのスキンは `.minecraft/CustomSkinLoader/LocalSkin/skins/<USERNAME>.png` に置く（既定の Legacy のパス）。【一次】[S14]
> 「Do not repost the mod to other websites without permission.」[S14]

### Mojang の規約（スキン・テクスチャ・パック）
詳しくは [Mojang利用ガイドライン](../rights/Mojang利用ガイドライン.md)。ここではスキンとパックに関わる文だけを挙げる。
- EULA は、ブロック1つ（テクスチャと「look and feel」を含む）を Mojang のものとし、自分で作った独自のものは自分のもの、としている。【一次】[S8]
> 「a single Minecraft block (including its textures and its “look and feel”) - we own that;」[S8]
- EULA は、Mojang が持つ知的財産に、ブロックのテクスチャとキャラクターのスキンを含めている。【一次】[S8]
> 「we retain ownership of our Minecraft intellectual property, which includes the game itself (including its content like the textures of our blocks and our character skins)」[S8]
- EULA は、mod・スキン・パックなどの内容でも、憎悪や極端な偏見を描くもの、違法行為を勧めるものを認めないとしている。【一次】[S8]
> 「However, content that portrays hate or extreme bias or encourages illegal activity is not permitted.」[S8]
- 利用ガイドラインは、Mojang の assets（アセット）に、ゲームのグラフィック・テクスチャ・画像・モデル・音、ゲームから撮った動画やスクリーンショットを含めている。【一次】[S9]

### キャラクターのスキンの権利（東北ずん子・ずんだもんプロジェクトの例）
VOICEVOX のキャラクターを使う場合の、見た目（イラスト・2次創作）の条件。音声の規約は movie の [VOICEVOX利用規約](https://github.com/mitsuo822/movie/blob/main/knowledge/audio/VOICEVOX利用規約.md)、立ち絵は [キャラクター立ち絵の規約](https://github.com/mitsuo822/movie/blob/main/knowledge/audio/キャラクター立ち絵の規約.md) を読む。ここではスキンを作る・使うときに関わる部分だけを挙げる。
- 対象のキャラクター: 東北ずん子・ずんだもん・東北イタコ・東北きりたんのほか、ガイドラインの地域の表に四国めたん・九州そら・中国うさぎ・中部つるぎが載っている。【一次】[S16]
- 自分で作る2次創作は使える。他人の2次創作を使うときは、その作者に別に権利があるので、それぞれ許可が要る。【一次】[S16]
> 「自身での2次創作は可能です。他人の2次創作を使うときは注意してください」[S16]
> 「他人の2次創作を利用するときには、イラスト制作者に権利が別途発生するのでそれぞれ許可を取る必要があります。」[S16]
- 例外として、禁止事項の「二次創作されたキャラクターの無断使用」の項に、ガイドラインに準拠したイラストなら二次創作イラストを使える、と書かれている。Q&A では、2次創作に（ず・ω・きょ）と書くとガイドライン準拠の意味になり、東北企業やクリエイターが自由に使える、としている。【一次】[S16]
> 「ただし、東北ずん子ガイドライン（このページのガイドライン）に準拠したイラストであれば二次創作イラストを使用することができます。」[S16]
> 「東北企業さん、クリエイターさんが自由に使えることになります」[S16]
- 服装やアクセサリーの変更はよいが、本人だと認識できる範囲で、とされている。【一次】[S16]
> 「東北ずん子ちゃんであると認識できる範囲でお願いします。」[S16]
- 個人の YouTube の広告やスーパーチャットは非商用の範囲。企業所属の YouTuber でも配信と、配信を編集した動画は非商用として無料。ただし所属企業以外のスポンサーが付く案件は有償。【一次】[S16]
> 「ただし、Youtuber、VTuberが所属する企業以外からのスポンサーのつく案件では有償利用となりますのでお問い合わせください。」[S16]
- 公式の3Dモデルは改造して再配布してよい。キャラクターの素材そのもの（イラスト・3Dモデル・音声）や、素材が主のものの販売は禁止。【一次】[S16]
- 禁止事項の「キャラクターのイメージを損なう利用」に、残虐な行為をする・されるものが入っている。【一次】[S16]
> 「キャラクターが残虐な行為をする、されるといった利用」[S16]
- 2次創作の Q&A でも、キャラクターのイメージを著しく悪くするものの例として、虐待をする・される、凶悪な殺人鬼になる、などを挙げて NG としている。軽いパロディは問題ない、としている。【一次】[S16]
> 「虐待をする/される、凶悪な殺人鬼になるなどキャラクターイメージを著しく悪化させるものに関してはＮＧです。」[S16]
- コピーライト表記は不要。ガイドラインは予告なく変更されうる。【一次】[S16]

## このチャンネルでの使い方（提案）
> ※この節は上の事実から導いた提案で、事実ではない。
- **格子が要る回は、まず Block Grid を試す。ただし ARR なので、動画に出す前に作者に条件を確かめるか、自作の格子パックにする。** Modrinth の grid 検索（26.3 で絞り込み）で全ブロックに格子を付けるものはこれだけだった。（根拠: [S12][S13]）
- **目盛りは自作の計測用ブロックで作る案。** 使わない色のコンクリートのテクスチャを、自分で描いた目盛り（1ブロック・半ブロック単位）に差し替え、計測する列にだけ並べる。全ブロックの格子より画面がうるさくない。一から自分で描けば、Mojang のテクスチャの派生物かを気にしなくて済む。（根拠: [S1][S8]）
- **High Contrast は計測映像の見やすさには当てにしない**（wiki の説明はメニューの GUI 向け。ワールドに効かないかは P0 で実機確認）。ワールドの見やすさは、格子パック・自作ブロック・シェーダー（[シェーダーと画質mod](シェーダーと画質mod.md)）で調整する。（根拠: [S1]）
- **パックは一覧の順番まで記録する。** 格子系は最上段。使ったパックの名前・版・順番・ライセンスを `mc/mods.yaml`（または各回の `experiment.yaml`）に書き、再撮影で同じ見た目を出せるようにする。（根拠: [S1][S11][S12]）
- **2人のキャラクターは、マネキン＋リソースパックのスキンでワールドに立たせる。** profile の `texture` に自作パック内のスキンを指定すれば、Mojang のアカウントにスキンを登録せずに済み、2人目のアカウントも要らない。ポーズ・`immovable`・`hide_description`（「NPC」の文字を消す）で、解説役として置ける。（根拠: [S4][S5][S7]）
- **キャラクターのスキンは自分たちで作る。** 配布サイトのずんだもん等のスキンは「他人の2次創作」にあたると読めるので、作者ごとの許可が要る（（ず・ω・きょ）の表記があるものは例外になりうるが、配布スキンでの扱いはガイドラインに書かれていない）。自作なら、東北ずん子・ずんだもんプロジェクトのガイドラインの「自身での2次創作」で使える。（根拠: [S16]）
- **キャラクターのマネキンを TNT・落下・溶岩の実験の被験体にしない。** マネキンはダメージを受けて倒れ、キャラクターが残虐な行為をされる利用は禁止事項にある。爆発の回は既定のスキン（Steve など）のマネキンか防具立てを使う。ガイドラインは例（虐待をする・される、凶悪な殺人鬼になる など）を挙げるが、物理実験の被験体が当たるかは書かれていないので、迷う場面は避ける。（根拠: [S4][S16]）
- **プレイヤー本人を録る場合**は、録画用アカウントのスキンを公式に登録するのが確実。ローカルのスキンを使う CustomSkinLoader はクライアント側の mod なので、録画する PC に入れる。（根拠: [S3][S14]）

## わかっていないこと・要確認
- **Flashback・Replay Mod の再生で、マネキンとリソースパックのスキン（profile の `texture`）が録画時と同じに描かれるか。** CustomSkinLoader のローカルスキンが再生にも出るか。→ P0 で【実測】。[Flashback](Flashback.md) の範囲とも重なる。
- **Block Grid（ARR）を動画に映してよいか。** ページに利用条件の記載がない。作者に確認が要る。
- **Block Grid は「シェーダー本体」のタグがある。** core シェーダーを使っている場合、Iris のシェーダーパックと同時に使えるか。→ 実機で確認。
- **26.3 の正式版のリソースパックの番号。** wiki の履歴の最後は pre1 の 97.1。正式版で変わったかは、実機の F3+V か `/version` で確かめる。
- **1.21.4 までの表示のパック（Grid-like Visible Block Edges）が 26.3 で動くか。** pack format の wiki は、番号がゲームの対応より大きいと互換性なし（incompatible）、合わないと一覧に警告が出る、としている（[S2]）が、古い番号のパックが読み込めるか・正しく描けるかは未確認。
- **組み込みの High Contrast パックがワールドの見た目に効くか。** wiki はメニューの GUI のコントラストを上げる、とだけ書いている（[S1]）。→ P0 で実機確認。
- **Faithful License の条件**（faithfulpack.net は読めないホスト）。
- **ずんだもん以外の VOICEVOX キャラクター**（春日部つむぎなど）の、見た目の2次創作・スキン化の条件。各キャラクターの公式サイトは今回読めていない。
- **The Skindex・NameMC などの規約の原文**（読めないホスト）。The Skindex（minecraftskins.com）の規約では、アップロードした人がスキンの所有権を持ち、サイトには運営・宣伝のための広いライセンスを与える、と第三者の記事が書いている、という検索要約だけがある（検索要約のみ・原文未読）。【未確認】[S17]
- マネキンを無敵にする方法（エンティティ共通の欄で無敵にできるか）は、今回読んだページに書かれていない。→ wiki の『Entity』の項か実機で確認。
- ずんだもん等のガイドラインは、Minecraft のスキン（64×64 のドット絵）に直接は触れていない。ドット絵化が「2次創作」の扱いでよいかは、文面からの当てはめになる。
