# チャンネルコンセプト

状態: 叩き台（2026-11-18）。チャンネル名とキャラクターは未決定。

## 1. 一言で

**「現実の物理で予想して、Minecraftで本気で確かめる」。**
毎回「現実の理論ではこうなるはず」→「MCで実測するとこうなった」→「なぜずれるのか／一致するのか」を見せる。
教養（物理の原理がわかる）とエンタメ（予想が裏切られる、装置の規模が大きい）を両立させる。

## 2. 動画の3系統

| 系統 | 中身 | 教養の軸 | エンタメの軸 | 例 |
|---|---|---|---|---|
| **A. MCは現実と同じ？** | MCの物理エンジンを実測して現実と比べる | 現実の法則と、ゲームがそれをどう近似しているか | 「MCの重力は地球の3倍以上」のような意外な数字 | 自由落下、終端速度、氷の摩擦、矢の放物線 |
| **B. 名実験をMCで再現** | 物理学史に残る実験をmodも使って再現する | 実験の歴史的な意味と原理 | 再現できるか／できないかのドキドキ | ガリレオの落下実験、ニュートンのゆりかご、永久機関 |
| **C. MCでしかできない極端実験** | 現実ではできない規模・条件で試す | 極端な条件で法則がどうなるか | 規模の大きさ、破壊、ありえない結果 | TNTキャノンで宇宙速度、高度1万ブロックからの落下 |

シリーズとして回すときは、A → B → C の順で、同じ題材を深掘りできると強い（例: 重力を測る → ガリレオの実験 → 重力modで月面と比べる）。

## 3. 1本の構成（長尺 8〜12分）

| 区間 | 目安 | 中身 |
|---|---|---|
| フック | 0:00〜0:30 | **結果の一番いい場面を先に見せる**＋問い（「重い金床と軽い豚、どっちが先に落ちる？」）。視聴者に予想させる |
| 予想 | 〜2:00 | 現実の物理ではどうなるか。理論と数字を簡潔に |
| 実験 | 〜6:00 | 装置の紹介 → 実行 → スローや多視点で見せる。計測グラフを画面に重ねる |
| 結果と謎解き | 〜9:00 | 実測値と理論値の比較。なぜずれるのか（MCの内部の式）、現実ではなぜそうなるのか |
| 発展・オチ | 〜11:00 | 条件を極端にする、modで「現実の物理」にしてみる、など。次回予告 |

- **数字は必ず実測値を出す。** 「たぶん」で物理を語らない（`CLAUDE.md` の確度の決まり）。
- グラフは「理論の線」と「実測の点」を重ねる形を基本とする。

## 4. ナレーション

- AI音声（VOICEVOX 系を第一候補。詳しくは movie リポジトリ）。
- **2人の掛け合い**を推奨: 解説役（博士役）と、視聴者の代わりに驚いたり間違えたりする聞き手役。教養の部分が説明だけにならず、エンタメとして見やすくなる。
- キャラクターは【未決定】。既存のVOICEVOXキャラクターをそのまま使うか、オリジナルのキャラクターにVOICEVOXの声を当てるか。どちらの場合も各キャラクターの利用規約とクレジット表記に従う。

## 5. ショート（長尺からの派生）

長尺の「一番の見せ場」を **ドパガキ編集**（高速カット、ズーム、全文字幕、効果音を盛る）で30〜60秒にする。
演出の仕様は movie リポジトリの `docs/ショート編集.md`。チャンネル固有の決まりは次のとおり。

- 冒頭1秒で結果か問いを出す。説明から入らない。
- 9:16 の映像は切り抜きではなく**撮り直す**。実験はコードで再実行できるので、縦画面用のカメラ位置で撮れる。
- 最後に長尺への導線（関連動画の設定）を付ける。

## 6. タイトル・サムネイル（叩き台）

- タイトルは「問い」か「意外な数字」の形にする（例: 「Minecraftの重力、実は地球の3倍以上だった」）。
- 使う数字は【実測】したものだけにする。
- Minecraftの名称やロゴを公式と誤解される形では使わない（Mojangの利用ガイドラインに従う。原文の該当箇所と、タイトル・説明欄で気をつけることは [knowledge/rights/Mojang利用ガイドライン.md](../knowledge/rights/Mojang利用ガイドライン.md)）。
