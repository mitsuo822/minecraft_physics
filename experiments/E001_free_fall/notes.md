# E001 メモ

- 狙い: T01（MCの重力は地球の何倍？）と T02（ガリレオの実験）の両方の素材を1回の実験で取る。
- 金床（落下するブロック）は着地すると「ブロックになる」ので、着地の判定は OnGround ではなく、エンティティが消えたtickで取る必要があるかもしれない【未確認】。
- アイテムは着地後に跳ねたり滑ったりする可能性がある。着地tickの判定方法は実測で決める。

## 実機の最初の実行で確かめること（2026-11-18 時点で未確認）

- [ ] `tick freeze` 中は `time query gametime` が進まず、`tick step 1` で1だけ進むか（runner の待ち合わせの前提）
- [ ] `tick step` で進めたときと、普通に動かしたときで、着地tickが同じか（`--keep-frozen` なしで普通に落として比べる）
- [ ] 召喚直後（t=0）の Motion が 0 か。召喚した tick に物理が1回動いていないか
- [ ] 豚が空中で自分から動かないか（水平方向の速度が0のままか）
- [ ] 着地の判定: 金床は消滅、豚とアイテムは OnGround=1 になるか。アイテムが跳ねないか
- [ ] 予想値（knowledge/mechanics/重力と空気抵抗.md）と当てはめた値が一致するか → 一致すれば【実測】に上げる

## 模擬サーバでの結果（参考。実測ではない）

予想値をそのまま入れた模擬サーバで、高さ256ブロックから落とした場合: 豚 110 tick（5.5秒）、金床と鉄インゴット 176 tick（8.8秒）。
現実の真空中なら7.23秒で同時。予想どおりなら「生物は物より速く落ち、重さは関係ない」という結果になる。
